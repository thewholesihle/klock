# Third-party notices

## Numeral typefaces

Klock embeds four typefaces, unmodified, to draw the clock's numerals. They are the property of the
**Indian Type Foundry** and are used under the **ITF Free Font License (FFL) 2.0**
(<https://www.fontshare.com>). Full licence texts: `assets/fonts/Panchang-FFL.txt`, `ClashDisplay-FFL.txt`, `Satoshi-FFL.txt`, `Melodrama-FFL.txt`.
The Satoshi Regular file in `assets/fonts` is used only by the website.

| Typeface | Style used | File |
|---|---|---|
| Panchang | Extrabold | `Panchang-Extrabold.otf` |
| Clash Display | Semibold | `ClashDisplay-Semibold.otf` |
| Satoshi | Black | `Satoshi-Black.otf` |
| Melodrama | Bold | `Melodrama-Bold.otf` |

Summary of the terms Klock relies on (read the licence itself for the authoritative text):

* Embedding the fonts in a desktop application, including commercial use, is permitted.
* The fonts must not be modified, subsetted or format-converted, and must not be redistributed as font files.
  Klock therefore embeds the original bytes, loads them from memory, and never extracts them.
* The fonts must not be offered to third parties as a font they can use to create their own content.
